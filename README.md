# Balatro Việt

Game bài poker roguelike phong cách Balatro, bản tiếng Việt, chạy hoàn toàn trên trình duyệt (HTML/CSS/JS thuần, không cần build).

**Chơi ngay:** https://hapo-longdd1.github.io/balatro-viet/

- 150 Joker, 22 Tarot, 12 Hành Tinh, 18 Huyền Bí, 32 Phiếu, 24 Thẻ, 28 Mù Trùm
- 15 bộ bài, 8 mức cược, chế độ Vô Tận
- Hỗ trợ máy tính và điện thoại (màn hình dọc / ngang), thêm vào màn hình chính để chơi toàn màn hình
- Tự lưu ván trong trình duyệt

Chạy local: mở `index.html`, hoặc `python3 -m http.server` rồi vào `http://localhost:8000`.

Dự án fan làm, không liên kết với LocalThunk hay Playstack.
